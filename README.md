An Aseprite script designed to manage layers by name. Enter a keyword to filter layers and groups, allowing for efficient control over their visibility, lock status, and opacity.

## Installation
1. Open Aseprite.
2. Open Scripts folder (`File` -> `Scripts` -> `Open Scripts Folder`)
3. Move Name-BaseLayerManager.lua to scripts folder.
4. Rescan scripts folder (`File` -> `Scripts` -> `Rescan scripts folder`) or restart Aseprite.
5. You can use script in `File` -> `Scripts` -> `Name-BaseLayerManager`.

## How to use Name-BaseLayerManager

* `Find Layer Name`   
Enter a keyword to filter layers and groups for further actions.

* `Layers Visible`  
Click button to show or hide layers and groups that include the keyword.

* `Lock Layers`     
Click button to lock or unlock layers and groups that include the keyword.

* `Layers Opacity`  
Use the slider to select a value, then click the button to adjust the opacity for all matching layers.

 
    

# Name-BaseLayerManager 中文說明

使用名稱控制帶有關鍵字之圖層與群組的 Aseprite script。  
可以一次控制所有名稱帶有關鍵字之圖層與群組的圖層開關、圖層鎖定，以及透明度調整。

## 安裝方法
1. 開啟 Aseprite.
2. 開啟 腳本資料夾 (`檔案` -> `腳本` -> `開啟腳本資料夾`)
3. 移動 Name-BaseLayerManager.lua 到 腳本資料夾.
4. 重新整理 腳本資料夾 (`檔案` -> `腳本` -> `重新整理腳本資料夾`) 或 重開 Aseprite.
5. 接著你就可以使用該工具 `檔案` -> `腳本` -> `Name-BaseLayerManager`.

## 如何使用 Name-BaseLayerManager

* `Find Layer Name`   
輸入關鍵字以便後續進行圖層與群組的控制。

* `Layers Visible`  
點擊按鈕以開啟或關閉所有含關鍵字之圖層與群組。

* `Lock Layers`     
點擊按鈕以鎖定或解除鎖定所有含關鍵字之圖層與群組。

* `Layers Opacity`  
滑動滑桿選擇想要的透明度，並按下按鈕調整所有含關鍵字之圖層的透明度。
